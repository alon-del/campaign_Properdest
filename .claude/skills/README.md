# Marketing skills

Subset of [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
(MIT, see `LICENSE-marketingskills`), selected for the Meta paid-campaign +
landing page work in `docs/landing-page-brief.md`:

- `product-marketing` — foundation skill other skills build on
- `cro` — landing page conversion optimization
- `copywriting`, `copy-editing` — landing page copy
- `signup` — registration flow
- `ads`, `ad-creative` — Meta campaign setup and creative
- `analytics`, `attribution` — pixel events, UTM tracking
- `ab-testing` — investors vs. buyers audience test
- `marketing-psychology` — persuasion/objection handling (FAQ, hero)
